## 4. Narrative

Between January 12, 2017, and January 14, 2017, an unauthorized party initiated three suspicious online transactions totaling $2,189.02 on Visa credit card C05061-K1 belonging to customer C05061.[^1] The unauthorized activity began with transaction 3660106 on January 12, 2017, at 07:08 for $850.28, which occurred in billing region 492 under product code C using device "RCT6303W87M7 Build/MRA58K | Windows 7 | ie 11.0 for desktop | ".[^2] On January 13, 2017, at 22:09, transaction 3660107 was processed for $890.79 under product code C in billing region 264 using device "RCT6303W87M7 Build/MRA58K | Windows 10 | ie 11.0 for tablet | 1920x1080".[^3] The final transaction, 3660108, was carried out on January 14, 2017, at 20:25 for $447.95 under product code C in billing region 492 using device "RCT6303W87M7 Build/MRA58K | Windows 7 | ie 11.0 for desktop | ".[^4] These unauthorized purchases were executed in bursts using devices new to the account operating behind an anonymous proxy.[^5] This pattern matches none of the documented fraud typologies, but the same template was identified across 14 other cards within 14 days, including C00450-K1, C02342-K1, C03528-K1, C05704-K2, C05770-K1, C06220-K1, C06962-K2, and C07212-K2, despite sharing no common devices.[^6] The activity is considered suspicious due to the rapid succession of high-dollar transactions, the use of anonymous proxies, the correlation to coordinated multi-card abuse, and prior confirmed fraud cases associated with card C05061-K1.[^7] Regarding the incident, the cardholder has not yet been contacted.[^8] The bank took containment actions by blocking card C05061-K1 and placing the connected cards on monitoring.[^9]
