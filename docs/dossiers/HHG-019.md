## Generalizable signal
- Rare-device ring: for each device_key (or DeviceInfo + id_30 + id_33 when the browser varies), if 3 or more distinct cards/customers use it within 7 days and all of those uses share ProductCD and amount within +-2% (or the same P/R email pair), flag all of them, even when each txn fits its own card. Weight by rarity: device_popularity of 10 or fewer lifetime cards makes the link strong. A generic profile (hundreds of cards) needs extra shared keys (email, counters, fixed amount).
